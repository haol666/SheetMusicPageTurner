# 乐谱自动翻页应用 - 设计文档

## 1. 项目概述

### 1.1 项目名称
SheetMusicPageTurner（乐谱自动翻页器）

### 1.2 项目目标
基于面部识别的iOS乐谱自动翻页应用，使用Vision框架实现面部表情（张嘴）检测触发翻页，解决演奏者双手不便翻页的问题。

### 1.3 核心功能
- 支持导入PDF格式乐谱
- 支持导入多张图片作为乐谱
- 张嘴自动翻页（使用Vision框架面部特征点检测）
- 手动翻页（点击屏幕左侧/右侧）
- 灵敏度可调节

### 1.4 技术栈
- **语言**: Swift
- **UI框架**: UIKit（代码创建视图）
- **面部识别**: Apple Vision框架（VNDetectFaceLandmarksRequest）
- **摄像头处理**: AVFoundation
- **PDF处理**: PDFKit
- **图片选择**: PhotosUI（PHPicker）
- **部署目标**: iOS 12.0+
- **架构模式**: MVC

## 3. 功能模块详细设计

### 3.1 琴谱管理模块（ScoreImportViewController）

**职责**:
- 展示已导入琴谱列表
- 提供导入新琴谱入口
- 删除已有琴谱
- 导航至琴谱浏览

**界面元素**:
| 元素 | 类型 | 说明 |
|------|------|------|
| tableView | UITableView | 琴谱列表 |
| addButton | UIBarButtonItem | 右上角"+"按钮 |

**数据流**:
```
用户点击"+" → ActionSheet (PDF/图片选择)
           ↓
    UIDocumentPicker (PDF) / PHPickerViewController (图片)
           ↓
    ScoreManager.importPDF() / ScoreManager.importImages()
           ↓
    刷新tableView → 自动导航至ScoreDisplayViewController
```

**关键实现**:
- 使用`UIDocumentPickerViewController`选择PDF文件
- 使用`PHPickerViewController`选择多张图片
- PDF页面通过`PDFKit`逐页渲染为UIImage
- 图片直接使用`UIImage(contentsOfFile:)`加载

### 3.2 琴谱浏览模块（ScoreDisplayViewController）

**职责**:
- 全屏显示琴谱页面
- 支持滑动翻页
- 支持点击翻页
- 支持缩放

**界面元素**:
| 元素 | 类型 | 说明 |
|------|------|------|
| scrollView | UIScrollView | 支持缩放的滚动视图 |
| pageImageView | UIImageView | 琴谱页面显示 |
| pageLabel | UILabel | 页码指示（如"第 1 / 10 页"） |
| pageControl | UIPageControl | 页面指示器 |

**翻页逻辑**:
```
点击位置判断:
- 屏幕左侧1/3区域 → 上一页
- 屏幕右侧1/3区域 → 下一页
```

**缩放功能**:
- 最小缩放: 1.0x
- 最大缩放: 4.0x
- 通过`UIScrollViewDelegate`实现

### 3.3 面部翻页模块（ViewController）

**职责**:
- 实时面部识别
- 张嘴检测触发翻页
- 手动翻页
- 灵敏度设置

**界面元素**:
| 元素 | 类型 | 说明 |
|------|------|------|
| scrollView | UIScrollView | 琴谱显示区域 |
| pageImageView | UIImageView | 当前页面 |
| cameraPreviewView | UIView | 前置摄像头预览（小圆形） |
| pageLabel | UILabel | 页码显示 |
| actionButton | UIButton | 手动翻页按钮 |
| settingsButton | UIButton | 灵敏度设置按钮 |
| noScoreLabel | UILabel | 无琴谱时提示 |

**摄像头设置**:
```swift
session.sessionPreset = .high
device = AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: .front)
output = AVCaptureVideoDataOutput(sampleBufferDelegate: self, queue: visionQueue)
```

**张嘴检测算法**:
```
1. 使用VNDetectFaceLandmarksRequest检测面部特征点
2. 获取outerLips（外唇轮廓）的10个特征点
3. 计算MAR (Mouth Aspect Ratio):
   MAR = |top.y - bottom.y| / |left.x - right.x|

   特征点索引:
   0: 左角    3: 上唇中点    6: 右角    9: 下唇中点

4. 如果MAR > mouthOpenThreshold，触发翻页
```

**灵敏度阈值**:
| 等级 | Threshold值 | 说明 |
|------|------------|------|
| 高 | 0.3 | 轻微张嘴即翻页 |
| 中 | 0.5 | 正常张嘴翻页 |
| 低 | 0.7 | 需要较大幅度张嘴 |

**翻页冷却机制**:
- 两次翻页间隔至少1秒（actionCooldown）
- 防止误触发

### 3.4 数据管理模块（ScoreManager）

**职责**:
- 琴谱数据的单例管理
- PDF解析与渲染
- 图片加载

**PDF渲染流程**:
```swift
for i in 0..<document.pageCount:
    page = document.page(at: i)
    pageRect = page.bounds(for: .mediaBox)

    renderer = UIGraphicsImageRenderer(size: pageRect.size)
    image = renderer.image { ctx in
        ctx.fill(pageRect)  // 白色背景
        ctx.cgContext.translateBy(x: 0, y: pageRect.size.height)
        ctx.cgContext.scaleBy(x: 1, y: -1)  // 翻转坐标系
        page.draw(with: .mediaBox, to: ctx.cgContext)
    }
```

    │                    ▼

    │              nextPage() → 翻至下一页

## 6. 关键技术点

### 6.1 Vision框架面部检测
```swift
let request = VNDetectFaceLandmarksRequest { [weak self] req, err in
    self?.handleFace(request: req)
}
let handler = VNImageRequestHandler(cvPixelBuffer: pixelBuffer,
                                     orientation: .leftMirrored,
                                     options: [:])
try? handler.perform([request])
```

### 6.2 前置摄像头镜像处理
```swift
// Vision的坐标系统需要镜像处理
// 使用.leftMirrored方向确保正确检测
orientation: .leftMirrored
```

### 6.3 安全域资源访问
```swift
if url.startAccessingSecurityScopedResource() {
    defer { url.stopAccessingSecurityScopedResource() }
    // 处理文件
}
```

### 6.4 线程安全
- 摄像头捕获在独立队列`visionQueue`处理
- UI更新必须回到主线程`DispatchQueue.main.async`

## 8. 使用说明

### 8.1 首次使用
1. 打开应用，底部TabBar显示"琴谱"和"翻页"两个标签
2. 点击"琴谱"标签
3. 点击右上角"+"按钮
4. 选择"从PDF导入"或"从图片导入"
5. 选择文件后自动进入浏览模式

### 8.2 翻页操作
| 操作 | 说明 |
|------|------|
| 张嘴 | 自动翻至下一页 |
| 点击屏幕右侧 | 翻至下一页 |
| 点击屏幕左侧 | 翻至上一页 |
| 双指捏合 | 缩放页面 |
| 点击"手动翻页"按钮 | 翻至下一页 |

### 8.3 灵敏度调整
1. 在"翻页"标签点击左上角"设置"按钮
2. 选择灵敏度等级（高/中/低）
